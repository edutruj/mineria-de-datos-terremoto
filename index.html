Códigos del cruce de datos

Documentación del proceso de minería de datos aplicado al dataset cruzado (EMA-DANE + RNT).

Objetivo: Unir la Encuesta Mensual de Alojamiento (EMA) del DANE con el Registro Nacional de Turismo (RNT) para analizar la ocupación hotelera por región en el período 2019–2026.

Pasos del proceso

1

Carga de datos crudos

Se cargan los dos archivos Excel: anex-EMA-jul2026.xlsx (ocupación) y thwd-ivmp.xlsx (RNT). Se leen 25 hojas del archivo EMA.

2

Limpieza de la hoja de ocupación

Se extrae la hoja "4.2 Porc Mens Ocupación.reg", se ajustan los encabezados (fila 10), se eliminan columnas vacías y se rellenan los años con ffill().

3

Transformación a formato largo (melt)

Se pasa de formato ancho (una columna por región) a formato largo con pd.melt(), obteniendo columnas: Año, Meses, region, ocupacion.

4

Procesamiento del RNT

Se limpia el archivo del Registro Nacional de Turismo (separar por comas, quitar comillas), se filtran solo los establecimientos de alojamiento turístico y se agrupa por región.

5

Mapeo de departamentos a regiones

Se crea un diccionario que agrupa los 33 departamentos de Colombia en las 12 regiones del DANE (ej: Risaralda, Caldas, Quindío → "Eje Cafetero").

6

Cruce de datasets (merge)

Se unen ambos DataFrames por la columna region con how="left", obteniendo un dataset final de 1188 filas × 7 columnas (12 regiones × 99 meses).

7

Exportación

El resultado se guarda como dataset_cruzado.xlsx listo para análisis y visualización.

Código Python completo

# 1. Carga de librerías
import pandas as pd
import numpy as np

# 2. Carga de datos crudos
rnt = pd.read_excel("../data/thwd-ivmp.xlsx")
rnt = rnt.iloc[:,0].str.split(",", expand=True)
rnt.columns = [
    "codigo_rnt", "estado_rnt", "razon_social_establecimiento",
    "departamento", "cod_dpto", "municipio", "cod_mun", "nit",
    "categoria", "sub_categoria", "habitaciones", "camas",
    "num_emp1", "ano"
]

# 3. Carga EMA (25 hojas)
ema = pd.read_excel("../data/anex-EMA-jul2026 (1).xlsx", sheet_name=None)

# 4. Limpieza de la hoja de ocupación mensual
ocupacion = ema["4.2 Porc Mens Ocupación.reg"]
ocupacion_limpia = ocupacion.copy()
ocupacion_limpia.columns = ocupacion_limpia.iloc[10]
ocupacion_limpia = ocupacion_limpia.iloc[11:]
ocupacion_limpia.columns = ocupacion_limpia.columns.astype(str).str.strip()
ocupacion_limpia = ocupacion_limpia.loc[:, ocupacion_limpia.columns.notna()]
ocupacion_limpia["Año"] = ocupacion_limpia["Año"].ffill()
ocupacion_limpia["Año"] = ocupacion_limpia["Año"].astype(str).str.replace("p", "", regex=False)
ocupacion_limpia["Año"] = pd.to_numeric(ocupacion_limpia["Año"], errors="coerce")

# 5. Melt: ancho -> largo
columnas_regiones = list(ocupacion_limpia.columns[3:15])
ocupacion_long = pd.melt(
    ocupacion_limpia,
    id_vars=["Año", "Meses"],
    value_vars=columnas_regiones,
    var_name="region",
    value_name="ocupacion"
)

# 6. Filtrar alojamientos del RNT
rnt_hoteles = rnt[rnt["categoria"].str.contains("ALOJAMIENTO", case=False, na=False)]
for col in rnt_hoteles.columns:
    rnt_hoteles[col] = rnt_hoteles[col].astype(str).str.replace('"', '', regex=False).str.strip()

# 7. Mapeo de departamentos -> regiones DANE
mapa_region = {
    "ANTIOQUIA": "Antioquia",
    "ATLANTICO": "Caribe", "CESAR": "Caribe", "MAGDALENA": "Caribe", "LA GUAJIRA": "Caribe",
    "CALDAS": "Eje Cafetero", "QUINDIO": "Eje Cafetero", "RISARALDA": "Eje Cafetero",
    "VALLE DEL CAUCA": "Pacífico", "CAUCA": "Pacífico", "NARIÑO": "Pacífico", "CHOCO": "Pacífico",
    "SANTANDER": "Santanderes", "NORTE DE SANTANDER": "Santanderes",
    "META": "Llanos Orinoquía", "ARAUCA": "Llanos Orinoquía",
    "CASANARE": "Llanos Orinoquía", "VICHADA": "Llanos Orinoquía",
    "AMAZONAS": "Amazonía", "CAQUETA": "Amazonía", "PUTUMAYO": "Amazonía",
    "GUAINIA": "Amazonía", "GUAVIARE": "Amazonía", "VAUPES": "Amazonía",
    "BOGOTA": "Bogotá D.C.",
    "CUNDINAMARCA": "Central", "BOYACA": "Central", "HUILA": "Central", "TOLIMA": "Central",
    "CORDOBA": "Golfo Morrosquillo y Sabana", "SUCRE": "Golfo Morrosquillo y Sabana",
    "SAN ANDRES Y PROVIDENCIA": "San Andrés y Providencia",
    "BOLIVAR": "Cartagena"
}

rnt_hoteles["region"] = rnt_hoteles["departamento"].str.upper().map(mapa_region)

# 8. Agrupar RNT por región
rnt_resumen = (
    rnt_hoteles
    .groupby("region", as_index=False)
    .agg(
        establecimientos=("codigo_rnt", "count"),
        habitaciones=("habitaciones", "count")
    )
)

# 9. CRUCE FINAL: EMA + RNT
dataset_final = pd.merge(
    ocupacion_long,
    rnt_resumen,
    on="region",
    how="left",
    indicator=True
)

# 10. Verificación y exportación
print(dataset_final["_merge"].value_counts())
dataset_final.to_excel("../data/dataset_cruzado.xlsx", index=False)
print("Dataset guardado correctamente")

Hallazgos clave

  • 2020: Caída drástica de ocupación por pandemia (mínimo: abril, 8.77% en Bogotá).
  • Eje Cafetero (Risaralda): Ocupación promedio ~44%, con recuperación gradual post-2020.
  • Cartagena y San Andrés: Ocupaciones más altas del país (60-75%).
  • Recuperación 2022–2026: Retorno a niveles pre-pandemia en la mayoría de regiones.
  • 2026 (terremoto): Se espera caída en Eje Cafetero, especialmente en meses post-agosto.
