# Proyecto de Minería de Datos — Turismo y Ocupación Hotelera en Risaralda

## Problema
¿Qué meses del año y qué segmentos de establecimientos de alojamiento en
Risaralda / Eje Cafetero presentan la mayor vulnerabilidad (caídas de ocupación
e ingresos reales) según los datos históricos 2019–julio 2026, para que la
Secretaría de Turismo de Risaralda y COTELCO prioricen la reactivación tras
el terremoto de agosto de 2026?
