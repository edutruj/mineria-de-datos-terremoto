# Proyecto de Minería de Datos — Turismo y Ocupación Hotelera en Risaralda

## Problema
¿Qué meses del año y qué segmentos de establecimientos de alojamiento en Risaralda / Eje Cafetero presentan la mayor vulnerabilidad (caídas de ocupación e ingresos reales) según los datos históricos 2019–julio 2026, para que la Secretaría de Turismo de Risaralda y COTELCO prioricen la reactivación tras el terremoto de agosto de 2026?

## Estructura del repositorio
* `/dataset_cruzado.xlsx` : Datos finales cruzados (EMA-DANE + RNT).
* `/index.html` : Tablero web interactivo con los indicadores, gráficos y validación de datos.
* `/mineria_terremoto_risaralda.ipynb` : Notebook con el análisis paso a paso (Calidad, EDA, Ingeniería de características, Modelo Predictivo).

## Fuentes de datos
* EMA – DANE: Encuesta Mensual de Alojamiento (enero 2019 – julio 2026)
* RNT: Registro Nacional de Turismo
